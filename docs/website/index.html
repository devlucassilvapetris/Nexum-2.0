Installation

Get started with Nexum v2.0 in minutes.

Prerequisites

Python 3.8 or higher
CUDA-capable GPU (required for LLM)
Minimum 16GB RAM (32GB+ recommended)
NVIDIA GTX 1080 / RTX 3050 (4GB+ VRAM)

Quick Start

# Clone the repository
git clone https://github.com/nexum/nexum2.0.git
cd nexum2.0

# Install dependencies
pip install -r requirements.txt

# Install the package
pip install -e .

# Initialize the system
nexum --init

API Reference

Simple and intuitive APIs for all system components.

Fine-tuning API

from nexum.ai.training import Trainer

# Initialize trainer
trainer = Trainer("config/ai/training_config.json")

# Run fine-tuning
output_dir = trainer.train()

RAG API

from nexum.ai.rag import RAGEngine

# Initialize RAG engine
rag = RAGEngine("config/ai/rag_config.json")

# Add documents
documents = [{"id": "doc1", "content": "..."}]
rag.add_documents(documents)

# Query
response = rag.query("What is Nexum v2.0?")

Model Serving API

from nexum.ai.serving import VLLMServe, RayDeployer

# Direct vLLM serving
vllm_serve = VLLMServe("config/ai/serving_config.json")
outputs = vllm_serve.generate(["Hello, world!"])

# Deploy with Ray Serve
deployer = RayDeployer("config/ai/serving_config.json")
deployment = deployer.deploy()

Evaluation API

from nexum.ai.evaluation import Evaluator

# Initialize evaluator
evaluator = Evaluator("config/ai/evaluation_config.json")

# Evaluate
results = evaluator.evaluate(dataset)
